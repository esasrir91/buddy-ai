# Valuation copilot — quick reference (India-aware; verify against standards)

> Original summary notes for grounding. Final opinions must follow ICAI Valuation
> Standards / IBBI rules and be issued by a Registered Valuer.

## Three approaches (reconcile, don't pick blindly)
- **Income approach (DCF):** PV of projected free cash flows + terminal value.
  Best for going concerns with forecastable cash flows.
- **Market approach (relative):** apply peer multiples (EV/EBITDA, EV/Revenue, P/E)
  or precedent-transaction multiples to the subject's metric.
- **Cost approach (asset-based):** net asset value / replacement cost. Useful for
  holding companies, asset-heavy or distressed entities.

## DCF inputs
- Discount rate = WACC. Cost of equity via CAPM: Ke = Rf + β × ERP.
  India: Rf ≈ 10Y G-Sec yield; ERP and β sourced/levered to the company.
- WACC = E/V·Ke + D/V·Kd·(1−tax).
- Terminal value (Gordon): FCF_n·(1+g) / (WACC − g); g must be < WACC and ≤ long-run growth.
- Always present a **range** via a sensitivity matrix (WACC × g), not a single point.
- Bridge: Enterprise Value − Net Debt = Equity Value; ÷ shares = per-share value.

## Early-stage / startup
- VC method: Post-money today = Exit value / target ROI (x). Exit value = exit earnings × exit multiple.
- Other methods: Berkus, Scorecard, First-Chicago (probability-weighted scenarios).

## Registered Valuer report — typical sections (ICAI VS / IBBI)
1. Background, purpose, intended users  2. Valuer identity, registration & independence
3. Valuation date, scope, standards  4. Asset/business & ownership description
5. Sources & procedures  6. Assumptions & limiting conditions
7. Approach & methodology  8. Key inputs with rationale
9. Workings & reconciliation  10. Opinion of value (range)  11. Caveats & signature

## Asset classes (IBBI registration)
- Securities or Financial Assets; Land & Building; Plant & Machinery.
